# FLEXI-Haz Simulation Study

This directory contains the code used for the simulation study reported
in the FLEXI-Haz project. The study evaluates prediction, coefficient
estimation, and statistical inference under a data-generating mechanism
with nonlinear and time-varying covariate effects.

The final reported experiment uses **200 independently generated
training datasets with (n=8000)** and a **single fixed test set with
(n=10{,}000)** shared across all replications and models.

## Models

Five models are evaluated:

1.  **Partially linear FLEXI-Haz**\
    \[
    `\log `{=tex}h(t`\mid `{=tex}X,Z)=`\theta`{=tex}\^`\top `{=tex}Z+g(t,X).
    \]

2.  **Fully nonparametric FLEXI-Haz**\
    All five covariates are passed through the flexible neural component
    and `Z=None`.

3.  **Zhong et al. (2022)**\
    A neural partially linear Cox model with a proportional-hazards
    structure.

4.  **Cox proportional hazards**\
    All five covariates are included linearly.

5.  **Random Survival Forest**\
    All five covariates are used as flexible predictors.

## Data-generating mechanism

The covariates are generated independently as

\[
X_1,X_2,X_3,Z_1,Z_2`\sim`{=tex}`\operatorname{Uniform}`{=tex}\[-1,1\],
\]

with

\[ `\theta`{=tex}\_0=(2,-1)\^`\top`{=tex} \]

and

\[ f(X)=0.2(X_1+X_2)+0.5X_1X_2+X_2\^3. \]

The hazard is

\[ h_0(t`\mid `{=tex}X,Z) =
0.1`\exp`{=tex}`\left`{=tex}{`\left`{=tex}(0.1+`\frac{f(X)^2}{2}`{=tex}`\right`{=tex})t+`\theta`{=tex}\_0\^`\top `{=tex}Z`\right`{=tex}},
`\qquad 0`{=tex}`\le `{=tex}t`\le 10`{=tex}. \]

The administrative horizon is

``` text
tau = 10
```

and independent random censoring is exponential with mean 30,
equivalently rate (1/30).

Event times are generated by inverse-transform sampling from the
analytically available survival distribution.

## Final simulation configuration

``` text
n_train        = 8000
n_replications = 200
n_test         = 10000
tau            = 10
censoring_mean = 30
base_seed      = 221100
test_seed      = 221100
theta_true     = [2, -1]
```

Survival probabilities are evaluated every 0.25 time units:

``` text
0.25, 0.50, ..., 10.00
```

Censoring-adjusted metrics use the corresponding grid strictly below the
administrative horizon:

``` text
0.25, 0.50, ..., 9.75
```

## Files

``` text
simulation_dgm.py
    Data-generating mechanism, exact cumulative hazard and survival,
    event-time simulation, and dataset serialization.

simulation_io.py
    Shared paths, JSON/CSV helpers, dataset loading, result paths,
    and completion checks.

metrics_survival.py
    IPCW survival metrics, survival bias/error calculations,
    and theta estimation/inference metrics.

generate_simulation_datasets.py
    Generates the 200 training datasets and the fixed test set.

tune_flexihaz_simulation.py
    Tunes partially linear or fully nonparametric FLEXI-Haz.

tune_zhong2022_simulation.py
    Tunes the Zhong et al. (2022) neural partially linear Cox model.

tune_rsf_simulation.py
    Tunes Random Survival Forest.

zhong2022_ph_common.py
    Shared Zhong-model architecture, fitting, baseline-hazard,
    prediction, and coefficient-inference utilities.

run_flexihaz_pl_replications.py
    Runs partially linear FLEXI-Haz across saved replications.

run_flexihaz_nonlinear_replications.py
    Runs fully nonparametric FLEXI-Haz across saved replications.

run_zhong2022_ph_replications.py
    Runs the Zhong et al. model across saved replications.

run_cox_ph_replications.py
    Runs Cox PH across saved replications.

run_rsf_replications.py
    Runs Random Survival Forest across saved replications.

aggregate_results.py
    Aggregates per-replication outputs into model-level and
    cross-model summary tables.
```

## Installation

Install FLEXI-Haz from the repository root:

``` bash
pip install -e .
```

Additional experiment dependencies include:

``` bash
pip install lifelines scikit-survival tensorflow
```

The FLEXI-Haz tuning code additionally requires Optuna, which is also a
package dependency.

## Reproducing the reported simulation

### 1. Generate the datasets

``` bash
python generate_simulation_datasets.py \
    --n 8000 \
    --n-replications 200 \
    --n-test 10000 \
    --tau 10 \
    --censoring-mean 30 \
    --eval-step 0.25
```

The generator creates `config.json`, `manifest.csv`, 200 training
datasets, and one fixed test set. The fixed test set is reused by every
model and every replication.

The synthetic `.npz` datasets may be omitted from version control
because they are deterministically regenerable from the stored
configuration and seeds.

### 2. Tune the neural models

The reported study tunes the neural models once on the first simulated
training dataset and then keeps the selected hyperparameters fixed
across all 200 replications.

For FLEXI-Haz:

``` bash
python tune_flexihaz_simulation.py \
    --model-type partial_linear \
    --n-trials 100 \
    --folds 5 \
    --max-epochs 2000

python tune_flexihaz_simulation.py \
    --model-type nonlinear \
    --n-trials 100 \
    --folds 5 \
    --max-epochs 2000
```

The search space used by the script contains one- to five-hidden-layer
ReLU networks with widths between 16 and 256, learning rate in
`[1e-3, 5e-2]`, batch size 100,000, and `grid_size="n"`.

The final selected configurations reported in the project are:

``` text
Partially linear FLEXI-Haz:
    hidden_layers = (32, 32, 64)
    learning_rate = 1.187e-3

Fully nonparametric FLEXI-Haz:
    hidden_layers = (64, 64, 64, 64)
    learning_rate = 1.387e-3
```

For Zhong et al. (2022):

``` bash
python tune_zhong2022_simulation.py \
    --n-trials 100 \
    --folds 5 \
    --max-epochs 2000 \
    --patience 30 \
    --batch-size 100000
```

The reported selected architecture is four hidden layers with 64 units
each and learning rate (2.463`\times10`{=tex}\^{-2}).

For Random Survival Forest:

``` bash
python tune_rsf_simulation.py \
    --n-trials 100 \
    --folds 3 \
    --n-estimators-tuning 200 \
    --final-n-estimators 500
```

The final reported structural parameters are:

``` text
min_samples_leaf  = 10
min_samples_split = 20
max_features      = 0.5
max_depth         = 20
max_samples       = 0.9
n_estimators      = 500
```

### 3. Run the 200 replications

Partially linear FLEXI-Haz:

``` bash
python run_flexihaz_pl_replications.py --start-rep 0 --end-rep 200
```

To fit several networks per replication and keep one, chosen by validation
loss or by the efficient score for the linear coefficients:

``` bash
python run_flexihaz_pl_replications.py --start-rep 0 --end-rep 200 \
    --n-restarts 5 --restart-selection efficient_score
```

These runs are written to a separate model folder
(`flexihaz_partial_linear_k5_efficient_score`), and each replication summary
records every restart's validation loss, coefficients and score.

Two further options of the same runner: `--theta-lr-mult 20` trains the
linear coefficients with 20 times the network learning rate (folder suffix
`_thetalr20`), and `--model-type zhong` fits the Zhong et al. (2022)
proportional-hazards model through the FLEXI-Haz estimator (`model_type="zhong"`:
no time input to the network, Breslow partial likelihood, additive projection
networks; folder `flexihaz_zhong_ph`). Both can be combined with `--n-restarts`.

Fully nonparametric FLEXI-Haz:

``` bash
python run_flexihaz_nonlinear_replications.py --start-rep 0 --end-rep 200
```

Zhong et al. (2022):

``` bash
python run_zhong2022_ph_replications.py --start-rep 0 --end-rep 200
```

Cox PH:

``` bash
python run_cox_ph_replications.py --start-rep 0 --end-rep 200
```

Random Survival Forest:

``` bash
python run_rsf_replications.py \
    --start-rep 0 \
    --end-rep 200 \
    --n-estimators 500 \
    --n-jobs -1
```

The replication runners support partial ranges, so the experiment can be
distributed across jobs. Completed replications are skipped unless
overwrite behavior is requested.

### 4. Aggregate results

``` bash
python aggregate_results.py --model all
```

The aggregation script creates per-model summaries and combined
cross-model tables.

## Evaluation

Prediction is evaluated using:

-   integrated Brier score;
-   mean Brier score across evaluation times;
-   time-dependent AUC;
-   mean AUC;
-   concordance index;
-   mean survival bias;
-   mean absolute survival bias;
-   survival RMSE.

Because the true survival function is known, direct prediction error
against the truth can be evaluated in addition to censoring-adjusted
metrics.

For partially linear FLEXI-Haz and Zhong et al. (2022), the experiment
also evaluates:

-   mean coefficient estimate;
-   coefficient bias;
-   empirical standard deviation;
-   mean estimated standard error;
-   empirical 90% CI coverage;
-   empirical 95% CI coverage.

## Output structure

The experiment writes outputs under a configurable output directory,
conventionally `simulation_outputs/` during execution.

Important generated artifacts include:

``` text
config.json
manifest.csv
tuning/
results/
```

For a public repository, large generated training datasets, the fixed
synthetic test `.npz`, smoke-test outputs, and serialized Optuna `.pkl`
files can be regenerated and do not need to be committed. Human-readable
tuning tables and aggregated result CSVs should be retained.

## Smoke testing

Before launching the full experiment, the scripts provide small
smoke-test modes. For example:

``` bash
python generate_simulation_datasets.py --smoke-test
python tune_flexihaz_simulation.py --smoke-test --model-type partial_linear
python run_flexihaz_pl_replications.py --smoke-test
```

Smoke tests verify execution only. Their outputs are not part of the
reported results.
